非官方简体中文**测试补丁 v0.2.0**。需要你自行合法安装受支持版本的游戏。下载包只包含译文、差分和自写脚本，不包含完整游戏程序或原始资产。

## 支持版本

| 项目 | 限定版本 |
|---|---|
| 游戏 | Melvor Idle 2 Demo，Windows |
| 游戏版本 | 0.11.2 alpha.4 |
| Steam App ID / Build ID | 5373510 / 26074343 |
| 补丁版本 | 0.2.0 |
| Python | 3.10 或更新版本，标准库，无额外 pip 依赖 |

安装器核对 EXE、游戏 DLL 和补丁的 SHA-256，不能只凭版本名称判断。**Steam 更新后如果哈希不匹配，安装会停止。** 不要修改脚本校验值强行安装。

## 安装

1. 关闭游戏，等待 Steam 更新或文件验证结束。
2. 从 Release 下载 ZIP 和 `SHA256SUMS.txt`，将 ZIP 完整解压到独立文件夹。不要把包内文件直接覆盖进游戏目录。
3. 确认 `python --version` 为 3.10 或更新版本。未安装者可从 [Python 官方网站](https://www.python.org/downloads/windows/) 获取；补丁不会自动安装软件。
4. 在游戏所在磁盘预留至少额外 **1.3 GB**，用于原文件备份及临时构建。
5. 双击 **`Install.cmd`**，输入自己游戏的安装目录。可在 Steam 的游戏管理菜单选择“浏览本地文件”，复制打开的文件夹路径。所选目录必须直接包含 `Melvor2.exe`。
6. 路径支持空格、中文，以及首尾配对的单引号或双引号。**没有默认目录；空输入、Q、Cancel、Ctrl+C 或输入结束都会取消，不自动安装。**
7. 安装器先验证适用 Demo 和哈希，再显示完整目标目录、状态及备份位置。确认无误后输入 **`INSTALL`** 才执行；直接回车或其他输入取消。
8. 看到成功提示后，从 Steam 正常启动游戏。此版本借用英语语言槽显示中文，不需要另外寻找中文选项。

也可在补丁文件夹运行：

```powershell
python -X utf8 patch.py install
```

高级用法可用 `--game "<游戏安装目录>"` 显式给定目录；仍须核对显示的目标并输入 `INSTALL`，没有跳过确认的选项。

安装会把原 EXE 备份到所选游戏目录的 **`.melvor-zh-cn-backup/Melvor2.exe`**。请保留此备份，卸载后也不会自动删除。重复安装会识别同一补丁并保持原样。v0.2.0 与 v0.1.0 的译文及资源差分相同，增加了路径输入、确认和公开发布整理，因此能够识别此前已安装的补丁。

## 卸载与恢复

关闭游戏，双击 **`Uninstall.cmd`**，输入当初安装补丁的游戏目录。核对目标与备份后，输入 **`UNINSTALL`** 确认。也可运行：

```powershell
python -X utf8 patch.py uninstall
```

卸载仅在当前 EXE 确为本补丁结果、同目录备份确为原版时恢复。它不会搜索磁盘或盲目恢复其他目录；文件被其他 Mod、更新或手工修改后会拒绝覆盖。若备份丢失、损坏或游戏已更新，可在 Steam 中右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性，恢复当前官方版本。

补丁脚本不读取或修改存档、Steam 云数据和游戏账户；无需删除或转换存档。

## EXE 与数字签名

游戏关闭了外置主资源包入口。本补丁在用户自己的 EXE 副本中追加中文资源、更新内嵌资源索引，**不修改机器代码、游戏 DLL 或发行补丁中的 project.binary**，不移除 DRM，也不启用被关闭的资源入口。

资源修改会使原 EXE 的数字签名失效。若系统安全软件阻止运行，请停止并保留提示，通过卸载或 Steam 验证恢复；不要关闭安全软件、更改系统执行策略或添加排除项。

## 翻译覆盖与限制

- 7,514 条去重译文，涵盖可提取的技能、物品、说明、界面、提示和教程文本。
- 修改 427 个界面资源中的 2,184 处可见文本属性；保留占位符、富文本标签和复数分支。
- 7,612 条提取候选中，98 条技术字段、编号、纯表达式或无须改变的内容不进入翻译表。
- 26 个主要涉及云存档的混淆动态文本构造未解码；图片、Logo 内的文字未改，部分表达式内部英文和其他运行时动态文字可能保留。
- **未完成真实游戏完整流程、主要界面布局、截图、截断和所有缩放比例验证。不能称为 100% 全汉化。**
- 已用游戏引擎进行四组主要字体的中文排版检查，依赖测试机器已有的系统字体回退，不分发新字体；其他电脑的显示仍可能不同。

具体测试与边界见 [VALIDATION.md](VALIDATION.md)。报告问题时提供游戏版本、补丁版本、界面原文及复现步骤即可，请勿上传存档、账户信息或完整游戏资产。
